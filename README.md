# 项目简介

## 核心功能
- 基于YOLOv8的钢筋横截面检测
- 支持图片、视频及摄像头进行检测
- 支持选择不同检测模型
- 界面实时显示目标位置、目标总数、置信度等信息
- 支持批量检测并查看所有检测结果
- 支持检测结果保存
- 支持自定义置信度和IOU阈值
- 可选择是否显示标签和原图

## 适用场景
- 钢筋结构质量检测
- 建筑工程自动化检测
- 横截面图像识别分析
- 批量图像处理场景

## 技术特点
- 采用Pycharm+Anaconda或VSCode+Anaconda开发环境
- 基于Python3.9、opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 包含1900张标注数据集，专注于rebar类别
- 提供完整源码、标注数据集、训练好的模型及项目运行教程
- 配置成功环境可直接使用，无需额外训练
